# Scorecast: анализ свежих игр Metacritic

Сервис раз в час забирает новые игры из раздела Games на Metacritic, сохраняет их в базу (или обновляет уже известные), строит резюме отзывов критиков и игроков, находит похожие игры и показывает всё это в веб-интерфейсе с мониторингом конвейера.

## Шаг 0. Кликабельный прототип

Демо: https://electrocow0-tech.github.io/metacritic-games/

Прототип собран одним HTML-файлом без сборщика (`docs/index.html`), это дизайн будущего фронтенда. В нём:

- 20 реальных свежих игр с Metacritic по состоянию на 2 ноября 2026: платформы с Metascore и Userscore, разработчик, описание, видео. Если оценки ещё нет (tbd), показываем «нет оценки». Такие игры не участвуют в средних и при сортировке уходят в конец списка.
- Обложки нарисованы плейсхолдерами (градиент и паттерн в стиле игры), картинки с сайта не копируются.
- Резюме критиков и игроков. Каждый тезис опирается на дословную цитату из отзыва, скрипт сверяет цитаты с исходными текстами.
- Радар «критики против игроков» по шести аспектам: бейдж расхождения, цитаты при наведении.
- Летсплей с таймкодами (демо-данные, в сервисе их даст связка YouTube Data API и Whisper).
- Похожие игры с объяснением, карта игр с кластерами, чат с базой, мониторинг конвейера с кнопкой «Запустить сейчас» (в прототипе конвейер симулируется).

### Откуда данные

Сайт Metacritic берёт данные из внутреннего JSON API `backend.metacritic.com`, защиты от ботов нет:

- `finder/metacritic/web?sortBy=-releaseDate&productType=games…`: лента SEE ALL с пагинацией;
- `composer/metacritic/pages/games/{slug}/web`: вся страница игры одним ответом (карточка, сводки оценок, первые отзывы);
- `reviews/metacritic/user/games/{slug}/platform/{platform}/stats/web`: Userscore по платформе;
- `reviews/metacritic/{critic|user}/games/{slug}/web?offset=&limit=`: отзывы с пагинацией.

### Пересборка данных прототипа

```bash
python3 tools/prototype/collect.py tools/prototype/.cache    # игры и оценки (нужен home.html главной /game/)
python3 tools/prototype/reviews.py tools/prototype/.cache    # отзывы
# LLM-разметка: резюме, аспекты, теги -> tools/prototype/.cache/ai_out_*.json
python3 tools/prototype/build_data.py                        # похожие, карта, вшивка JSON в docs/index.html
```
